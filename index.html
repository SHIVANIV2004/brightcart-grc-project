How to run the original workbook

  1. Open BrightCart_GRC_Workbook.xlsx in desktop Excel.
  2. Read About and Methodology, then select Dashboard to view the existing output.
  3. Set Formulas → Calculation Options → Automatic if needed, then press F9.
  4. For a practice run, save a copy and change Methodology!B4 from 2 November to 24 November 2026. Dashboard!B28 should move from one overdue action to two if action statuses stay unchanged.
  5. Inspect Remediation Tracker: A-005 becomes 11 days overdue; A-010 becomes 25 days overdue.
  6. Keep the Offboarding Test's original blank disable date for L-0462: it describes the original test, while A-001 records later corrective action.
